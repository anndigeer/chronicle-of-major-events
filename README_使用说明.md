# 九江市委大事记自动整理工具（v2）

## 一、主要功能

- 同时抓取 **九江市政府“今日九江”** 和 **九江新闻网“九江时政”** 两个新闻列表。Excel 固定保留 **“九江市政府”**、**“九江新闻网”** 两个工作表。
- 按年份增量获取新闻列表，并抓取新新闻的标题、正文，缓存在 `jiujiang_cache.sqlite3`。重新运行时不会反复下载已成功的正文。
- 标题或正文包含名单中的姓名时，默认自动选中。默认姓名放在 `jrjj_config.json`，可以随意增删；还会尝试从凤凰江西指定“政要库左”区域追加姓名。凤凰访问失败时仍能使用本地名单。
- 允许人工修改筛选结果。**E 列“人工选择”**填入 `收录` / `排除`；原来在标题或日期单元格上填充**黄色背景**，仍然代表“收录”。
- 生成 `市委大事记（YYYY年M月）.docx`，**按发布日期从早到晚**，相同标题且日期相差不超过两天的文章跨来源去重。字体、页边距、首行缩进、行距与上传的 Word 样式相近，并包含页码。
- 自动备份原有 Excel；原来人工制作的 Word 不会被覆盖，自动生成的 Word 再次更新前会备份。

## 二、安装（Windows / PowerShell）

建议 Python 3.10 及以上版本。把本压缩包里的全部文件解压到同一个文件夹，再把原来的 `jiujiang_news.xlsx` 复制进此文件夹。原 Word 文件无需复制；它用于排版参考，v2 会创建**目标月份的新 Word**。

```powershell
py -3 -m pip install -r requirements_v2.txt
```

如果习惯双击，可以先运行 `首次安装依赖.bat`，安装完成后双击 `一键采集生成.bat`。

## 三、直接运行

```powershell
py -3 jrjj_v2.py
```

以上命令会自动：获取两站当前目标年度的新增列表、提取正文、匹配人名、保存 `jiujiang_news.xlsx`、导出上个月的大事记。

例如 **2026 年 10 月运行，默认生成 `市委大事记（2026年9月）.docx`**。本工具以**发布日期**决定月度归属，而非报道所说的活动发生日期。

第一次运行可能较慢，因为需要获取历史列表并保存新文章正文。以后运行将主要处理新增内容。

## 四、人工复核之后，不必再抓完整列表

打开 Excel，查看两张工作表：

| 列 | 含义 |
|---|---|
| A | 新闻标题（可直接点击打开原文） |
| B | 发布日期 |
| C | 自动匹配结果 |
| D | 命中姓名 |
| E | 人工选择（可填 `收录` / `排除`） |
| F | 正文抓取状态 |
| G | 原文链接 |
| H | 未成功抓取时的错误说明 |

人工选择的优先级：**E 列“排除” > E 列“收录” > 原有黄色填充 > 自动姓名匹配**。不需要人工指定的记录，E 列保持空白即可。

保存并关闭 Excel 后运行：

```powershell
py -3 jrjj_v2.py --mode export
```

该命令**不重新获取新闻列表**，只补抓目标月份尚未成功的正文，然后重新生成 Word。修改姓名配置后重新运行也会用缓存重新计算匹配。

只更新 Excel、正文，不生成 Word：

```powershell
py -3 jrjj_v2.py --mode sync
```

## 五、修改日期与姓名

指定需要制作的月份：

```powershell
py -3 jrjj_v2.py --month 2026-02 --mode export
```

需要补抓某个年度完整列表时：

```powershell
py -3 jrjj_v2.py --month 2026-09 --full-scan --max-pages 250
```

打开 `jrjj_config.json`，按需增删 `names` 中的人名。若不想自动采集凤凰名单，把 `fetch_ifeng_names` 改为 `false`。若只检查标题、不检查正文，把 `include_body_matches` 改为 `false`。

## 六、网站改版或限制访问时怎么办？

程序采用多套列表和正文解析方式，并尝试跟随网站 HTML 中实际的“下一页”链接，但**网页动态加载、访问控制以及以后再次改版仍可能导致失败**。

发生“已访问但无法识别列表”时，程序会把对应 HTML 放到 `debug_html` 文件夹。可以把其中的文件发给开发者进一步适配（先检查是否含敏感内容）。

在 `requests` 无法读取 JS 动态页面时，可以尝试安装浏览器回退：

```powershell
py -3 -m pip install playwright
py -3 -m playwright install chromium
py -3 jrjj_v2.py --browser
```

`--browser` **不是绕过网站访问权限或验证码的工具**，仅用于网页动态渲染。必要时应通过网站提供的公开接口或取得网站授权。程序遇到 429 限流会按退避策略重试，避免高频请求。

如果某篇新闻的正文失败，F 列会显示“失败”，H 列显示原因；系统**不会把空白正文写进 Word**。下次运行会尝试补抓。

## 七、目录中的文件

- `jrjj_v2.py`：主程序。
- `jrjj_config.json`：用户可自行修改的姓名、超时、翻页和限速配置。
- `requirements_v2.txt`：依赖列表。
- `一键采集生成.bat`：Windows 双击运行。
- `首次安装依赖.bat`：Windows 双击安装依赖。
- `test_jrjj_v2.py`：离线回归测试，可执行 `py -3 -m unittest -v test_jrjj_v2.py`。
- `jiujiang_news.xlsx`：运行后更新，在首次运行前请放入原始 Excel。
- `jiujiang_cache.sqlite3`：正文数据库，程序首次运行自动创建。**以后请与 Excel 一起保留，不要删除**。
- `备份/`：被更新前的 Excel、Word 备份。
- `debug_html/`：抓取异常时保存的页面源代码。

## 八、注意

1. **运行程序前先关闭**已打开的 `jiujiang_news.xlsx` 或目标 Word，否则 Windows 可能阻止保存。
2. 初次升级会把原来的“九江新闻”工作表重命名为“九江市政府”，保留旧记录与黄色标记。旧的 `HYPERLINK` 公式也会转换为普通 Excel 超链接以避免兼容问题。
3. 默认只抓取**目标月份所在年份**；例如 2027 年 1 月默认制作 2026 年 12 月，并抓取 2026 年新闻。
4. 不要在程序运行途中直接编辑 Excel；需要手动筛选时先等待程序结束。
5. 本发布包已通过离线列表解析、旧工作表迁移、中文关键词、跨站去重及 Word 生成测试。**由于当前执行环境无法直接连通九江市政府官网，尚不能宣称两站生产环境已全部实测通过。**
